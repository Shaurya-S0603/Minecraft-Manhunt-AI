# Modpack design

Plan a Fabric 1.21.11 client modpack and a dedicated server pack as separate deliverables.

## Client

Include only compatible client mods, the optional Manhunt UI, and configuration permitted by redistribution licenses.

## Server

Include Fabric Loader/API, compiled bridge mod and optional Carpet dependencies.

## Beyond modpack

Ship Python and Node applications separately with install instructions; `.mrpack` cannot launch those runtimes by itself.
