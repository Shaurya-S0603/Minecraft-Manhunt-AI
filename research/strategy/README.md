# Sourced Strategic AI — v0.7.12

This folder has a provenance record for two publicly discussed Minecraft-completion systems.

**Mine AI MCP:** https://github.com/aibengineering/mine-ai-mcp (MIT); published trace at https://huggingface.co/datasets/aibengineering/beat-the-game-minecraft (CC BY 4.0). The documented server and run use Java 1.21.4, not our 1.21.11 Carpet controller. Downloadable trace records do **not** contain a compatible trained motor-policy checkpoint.

**Gemini 4 Argon Minecraft completion research:** https://arxiv.org/abs/2610.22319 (published October 15, 2026). The study reports a four-agent team and 2,783 generated programs during a 27-hour run. It is a description of planning, memory and retry dynamics, not a downloadable model or 1.21.11 movement training set.

## What was actually implemented

1. 	A small bounded tactical advisor for Hunter pursuit and Runner escape, inspired by goal persistence and observed-evidence feedback.
2. 	Per-role persistent *local* separation-change feedback under `runtime/strategy/`.
3. 	An optional research extractor for **metadata only**, accepting the licensed Mine AI MCP `transcript.jsonl` downloaded by the user from the Hugging Face dataset. It retains tool names, groupings and whether results were flagged as errors; it deliberately strips prompts, coordinates, free-text responses, thinking blocks and code.

The external trace is **not** used as a Manhunt success reward: its observations are from a Minecraft-completion task in a different game version. Our skill models and normal terrain guardrails remain separate.

### Import research data

From the project folder, save the published trace as `transcript.jsonl` and run:

```powershell
python -m quickstart.strategy_import --input transcript.jsonl
python -m quickstart.strategy_report
```

Alternatively, drag the downloaded trace onto `training/launchers/IMPORT_MINEAI_TRACE.bat`. **Do not execute external prompt text or model-generated code.**

### In-game behavior

- Hunter: direct pursuit with optional short-horizon intercept, maximum 3 blocks of lookahead; uses existing observed target and A*.
- Runner: existing escape path with optional gentle lateral variation (still heading away from the Hunter).
- Both: choose goals in windows of ~2.5 seconds, keep a separation-change score, save role-specific local feedback.
- No new attack, teleport, mining, swimming, climbing or block-placement command is generated by this strategy layer.
- Disable safely by setting `MANHUNT_STRATEGY=0` in the same shell before launching the match. This retains the original target decision behavior.

### Limitations

The tactical outcome estimate is based on movement separation, not reliable attribution, combat wins or hold-out evaluation. The strategy is a conservative online heuristic, **not a finetuned Gemini or Mine AI model**. Actual in-game performance needs user testing. The traces were not available directly in this isolated environment and are not included in the release.
