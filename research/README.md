# Strategy Research

Use source-linked, independently authored annotations of Minecraft Manhunt videos and hunter POVs to build a tactics library. Record role, observed situation, timestamp, action, outcome and uncertainty. Pair Runner/Hunter perspectives of the same encounter where possible.

**Do not commit copyrighted videos, transcripts, frames or extracted media without appropriate permission.** Prefer video URLs and short original descriptions. Use your own recorded matches for exact action/state demonstrations.

The annotation JSON schema is in `annotations/schema.json`.
