# Manhunt Hunter v1 baseline review

## Evidence and scope

The review covers all eight supplied references. The entries summarize the repository documentation or the author's published feature description. Compatibility labels describe the published builds. Claims from closed projects are feature claims. A blank or undocumented feature means the source reviewed did not establish it. This review does not rank catch rates, server performance, or survival ability.

The implementation starts from the separately recovered **v8.0.2 Clean Source Edition**. The GitHub README was cross-checked through the repository connector and lists v0.7.16. The recovered archive has the newer inventory monitor and resource hotfix. The separately attached file with “(1)” in its name was unavailable.

## Comparison protocol

The improvements above are implementation differences. To measure performance, pre-register a single mode, fixed seed and fixture list, runner behavior and game time limit. Compare v1 learning on versus off first on identical held-out rounds. Record both aborted and completed rounds, and retain the underlying match rows. Compare third-party builds only where versions, fixtures, win rules and teleport/gear settings can reasonably be aligned. Use time to first verified damage, median distance, survival, pickups, completed-round win rate and server tick performance as separate measurements. See [TESTING.md](TESTING.md).
