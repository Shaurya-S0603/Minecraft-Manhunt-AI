# Release checklist

- Not a functional checklist yet: fill it as you implement. This list is the target release acceptance process.

## Compatibility

Confirm real Minecraft 1.21.11 server startup; Fabric bridge; selected bot adapter; head start; world resets; dependency license review.

## Security

Check no credentials or private save folders are packaged; local network endpoints are protected.

## User experience

A tester can set a role, choose a seed policy, start and finish a survival match, and safely return to setup.
